# Vanilla Settings

**Vanilla Settings** is a lightweight client-side utility mod designed for **Vanilla+** players, content creators, and perfectionists who use optimization mods (like Sodium, Lithium, or Mod Menu) but want to keep the clean, authentic look of unmodified Minecraft.

---

### ✨ Key Features

* **Vanilla Video Settings:** Restores access to the classic vanilla video settings screen even when Sodium is installed.
* **Clean F3 Debug Screen:** Automatically filters out lines added by mods from the F3 screen-hiding them-while keeping all vanilla lines.
* **Hide Mod Menu Buttons:** Removes the "Mods" button from both the Title Screen and the Pause Menu, restoring the original button layout and Realms notifications. *(You can still open Mod Menu anytime using its assigned hotkey!)*
* **Clean Branding:** Removes the `(modded)` tag and `*` from the window title, main menu version string, and F3 brand info.
* **Hide "Built-in" Pack Labels:** Visually hides built-in resource packs from mods; they can still be enabled or disabled, but they simply do not appear in the list.
* **Keybind Decluttering:** Includes a built-in search and toggle menu to hide unused mod keybinds from the Controls screen without breaking their functionality.

---

### ⚙️ Configuration

Every feature can be toggled individually in-game via **Mod Menu → Vanilla Settings**.

### 📦 Requirements

* **Minecraft:** 26.3
* **Mod Loader:** Fabric
* **Dependencies:** Fabric API, Sodium, ModMenu
